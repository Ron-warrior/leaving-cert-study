# Archive

Non-runtime, historical material. Nothing here is loaded by the Astro app.

- `screenshots/` — one selected snapshot per screen from the November 2026 UI
  work. Superseded iterations were removed.
- `source-material/cs/` — the Golden Key textbook PDF and the 2024 exam-page
  images used while writing the Computer Science notes. These are reference
  sources, not app content.
- `WORKLOG.md` — the development log from the web-first migration. Paths, page
  counts and references to the removed Rust/legacy app reflect the time of each
  entry, not the current project layout.

Keep this folder out of the production build and out of any future deployment.
